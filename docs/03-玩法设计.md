# 玩法设计：从平民到星区霸主

> 设计目标：让一个上班摸鱼的人，用 30 秒一次的操作，打一场有取舍、有邻居、有背刺的星际 4X。
>
> 所有数值都是**设计目标值**，不是最终平衡值。实现时以「节奏」为准，不要死扣数字。

---

## 一、设计目标

### 体验曲线

| 阶段 | 玩家感受 | 设计手段 |
| --- | --- | --- |
| 第 1 分钟 | 「这到底是什么？」 | 任务栏伪装、阿刻吐槽、一个按钮切入 |
| 第 5 分钟 | 「我会了。」 | 三座基础建筑、人口分配、第一条科技 |
| 第 10 分钟 | 「我得做个决定。」 | 阵营、科技二选一 |
| 第 15 分钟 | 「我想要更多。」 | 第一个殖民地、第一支舰队、第一个邻居 |
| 第 30 分钟 | 「我得选边了。」 | 打还是谈、第一次冲突、第一份合同 |
| 第 2 小时 | 「战争开始了。」 | 军种克制、贸易路线、第一次掠夺 |
| 第 4 小时 | 「我们不能都赢。」 | 占领、背刺、共享危机 |
| 第 6 小时 | 「再来一局。」 | 结算、结局、下局新地图 |

### 四条硬规则

1. **30 秒规则**：任何一次操作，30 秒内完成。
2. **六行规则**：弹窗一屏最多 6 行可操作内容。
3. **不红点规则**：不用红点、弹窗、音效催玩家。
4. **不归零规则**：被打崩不等于出局，可以流亡、可以复仇、可以当搅屎棍。

## 二、核心循环

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   发展（资源） → 人口 → 科研 → 制造 → 军队 → 殖民 → 占领 → 开发 │
│        ↑                                                  │  │
│        └──────────────────── 反哺 ────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 每一环的「决策点」

| 环节 | 你做什么 | 真正的决策 | 失败的样子 |
| --- | --- | --- | --- |
| 发展（资源） | 建电站、矿场、农场 | 能源先给民用、科研还是军工 | 停电、缺矿、饿肚子 |
| 人口 | 分配职业、提升士气 | 当工人、学者还是士兵 | 罢工、人口停滞 |
| 科研 | 选科技路线 | 两条互斥路线选哪条 | 科技树点歪，中期乏力 |
| 制造 | 工厂排产、造舰船模块 | 爆合金还是攒舰队 | 有矿没合金，有船没模块 |
| 军队 | 配舰队、打仗 | 侦察、截击、轰炸、主力舰、支援舰怎么配 | 被克制，全军覆没 |
| 殖民 | 占星球、建殖民地 | 占肥球还是抢航道 | 补给线太长，殖民地叛乱 |
| 占领 | 打中立区、打玩家 | 劫掠一波还是长期占领 | 占得住守不住，被反推 |
| 探险 | 组远征队、选目的地 | 深入遗迹还是见好就收 | 损失舰队、指挥官被俘 |
| 开发 | 升级首都、修奇观 | 堆经济、堆奇观还是堆防御 | 分数高但守不住 |

### 循环的节奏

- **前期**：资源 → 人口 → 科研，三步走。
- **中期**：科研 → 制造 → 军队，开始有牙；用短途探险找第一块稀有资源。
- **后期**：殖民 → 占领 → 开发，开始抢地盘；用深空探险赌旗舰和星门。
- **终局**：所有环节同时被压榨，做一个取舍。

## 三、单局结构

### 标准局：6 小时，三个时代

| 时间 | 时代 | 主题 | 玩家目标 |
| --- | --- | --- | --- |
| 0–10 分钟 | 苏醒 | 教学 | 建电站、矿场、农场，分配人口 |
| 10–120 分钟 | 第一时代：立足 | 经济 | 第一个工厂、实验室、殖民地、第一条贸易线 |
| 120–240 分钟 | 第二时代：扩张 | 冲突 | 舰队、贸易、掠夺、探险、中立区、第一次玩家接触 |
| 240–350 分钟 | 第三时代：审计 | 危机 | 静默者、奇观、深空探险、终局抉择 |
| 350–360 分钟 | 结算 | 收束 | 最后一波、结算、结局 |

一个时代约 2 小时。
第一个时代包含 10 分钟教学，所以略短。
标准局适合一个工作日：上午开局，午休看一眼，下午收尾。

### 其他节奏

| 模式 | 时长 | 时代长度 | 适合 |
| --- | --- | --- | --- |
| 快速局 | 2 小时 | 40 分钟 | 午休、等人、试玩法 |
| 标准局 | 6 小时 | 2 小时 | 默认、一个工作日 |
| 朋友局 | 6 小时 | 2 小时 | 低危机、不想太累 |
| 长局 | 12 小时 | 4 小时 | 跨半天、周末 |
| 马拉松 | 24 小时 | 8 小时 | 跨周末，自定义，不推荐默认 |

### 贸易、掠夺与探险是横切层

贸易、掠夺和探险不单独占一个时代。
它们横切在「资源 → 军队 → 殖民 → 占领」之上：

- 前期：用贸易补缺口，用护航防海盗，用短途探险找第一块遗物。
- 中期：用掠夺抢别人的贸易线，用贸易养更大的舰队，用黑市把星际代币（ST）换成稀有模块。
- 后期：用封锁和关税逼对手犯错，用护航和保险保自己的命脉，用深空探险赌星核。
- 终局：贸易线是静默者的优先目标，遗迹里可能藏着静默者的弱点，掠夺者也可能变成守卫者。

核心循环回答「怎么变强」。
贸易、掠夺与探险回答「从谁身上变强、从哪片废墟里变强，以及谁在从你身上变强」。

### 共享时钟

- 联机模式使用**共享时钟**，所有人同一 tick。
- tick 频率：2 Hz（每 0.5 秒一次逻辑推进），UI 每秒刷新一次。
- 玩家指令提前 3 个 tick 提交（约 1.5 秒），所有人同时执行。
- 全房间可以投票暂停；暂停时不能操作，但可以看面板、聊天。
- 所有人离线超过 60 秒，自动暂停。
- 至少一人在线时，时钟继续；离线玩家进入托管。

### 单机节奏

- 可以暂停。
- 可以加速 1x / 2x / 4x。
- 离线按时间补算，最多 12 小时，效率 60%。
- 本地存档，和联机数据完全隔离。

## 四、资源系统

### 基础资源（六种）+ 星际代币

| 资源 | 来源 | 主要用途 | 短缺后果 |
| --- | --- | --- | --- |
| 能源 EN | 电站 | 建筑运行、实验室、护盾 | 全局效率下降，建筑停摆 |
| 矿物 MIN | 矿场 | 建筑、工厂、舰船 | 造不了东西 |
| 食物 FOOD | 农场 | 人口、舰队、殖民地 | 士气下降，人口负增长 |
| 合金 ALY | 工厂（矿物 + 能源） | 高级建筑、舰船、殖民地 | 中期卡脖子 |
| 科研 RES | 实验室（能源 + 人口） | 科技 | 科技落后，被克制 |
| 影响力 INF | 领土、契约、事件 | 外交、占领、奇观 | 外交被动，占领不稳 |
| 星际代币 ST | 市场出售、合同、贸易路线、掠夺、探险 | 黑市、雇佣、情报、赎金、保险、政治献金 | 买不到稀有货，雇佣和外交受限 |

### 稀有资源（探险 / 黑市）

稀有资源不参与普通生产，也不能用矿场刷。
它们只能通过探险、黑市、掠夺或玩家合同获得。

| 稀有资源 | 主要来源 | 用途 |
| --- | --- | --- |
| 遗物 REL | 遗迹带、古战场、黑市 | 稀有科技、奇观、独特舰船模块 |
| 星核 COR | 深空异常、静默区边缘、黑市 | 旗舰、超级武器、星门 |
| 数据核心 DATA | 漂流方舟、静默者前哨、遗迹 | 科技解锁、地图情报、剧情真相 |

稀有资源有独立保险库，不占普通仓储。
它们可以被掠夺、被黑市收购、被玩家合同抵押。
探险是主要来源，黑市是补给，掠夺是捷径。

### 资源设计原则

1. **每种资源都有至少两个用途。**
   食物既能养人口，也能养舰队；合金既能造建筑，也能造舰船。
   玩家永远在「现在花」和「以后花」之间做选择。

2. **每种资源都有至少两个来源。**
   矿物可以挖，也可以拆遗迹；食物可以种，也可以贸易；影响力可以赚，也可以抢。
   没有死局。

3. **仓储有上限。**
   上限由首都等级和仓库建筑决定。
   超过上限的资源按 20% 折算成「废料」，可以换少量影响力。
   逼玩家花钱，不让仓鼠无限囤。
   星际代币和稀有资源不占普通仓储，不受这条限制。

4. **不要三缺一。**
   任何一条生产线都不应该被单一资源卡死。
   如果玩家缺合金，应该可以通过贸易、拆船、事件、黑市解决。

5. **贸易和掠夺是两条外部资源通道。**
   贸易用时间、路线和信誉换资源；掠夺用舰队、风险和仇恨换资源。
   两者互为因果：贸易越肥，掠夺越值；掠夺越多，护航越贵。

6. **价格是活的。**
   战争、封锁、危机、静默者都会影响市场。
   玩家不仅要会生产，还要会判断「现在卖还是以后卖」。

7. **星际代币是流动的，不是囤的。**
   它不能靠建筑生产，必须通过交易、掠夺、探险、悬赏获得。
   黑市是主要出口；代币不计入霸业值，花出去才算数。

8. **稀有资源是探险的理由。**
   普通资源可以种，稀有资源只能冒险、交易或抢。
   没有探险，就没有旗舰、星门和超级武器。

### 资源循环图

```
能源 ──→ 矿场 ──→ 矿物 ──→ 工厂 ──→ 合金 ──→ 舰船 / 建筑 / 殖民地
  │                 │                    │
  │                 └──→ 建筑升级         └──→ 奇观
  │
  ├──→ 实验室 ──→ 科研 ──→ 科技
  │
  └──→ 农场 ──→ 食物 ──→ 人口 / 舰队

基础资源 ──→ 市场 / 合同 ──→ 星际代币 ST ──→ 黑市 ──→ 稀有科技 / 模块 / 雇佣
    ↑                                                          │
    └────────────────── 生产 / 扩张 / 舰队 ←───────────────────┘

探险 / 掠夺 ──→ 稀有资源 REL / COR / DATA ──→ 黑市 / 合同 ──→ ST
```

## 五、人口系统

### 人口单位

- 1 人口 = 1 个劳动力。
- 开局 12 人口，全部未分配。
- 人口既是生产力，也是兵源、殖民者和舰队船员。
- 人口不是抽象数字：每一单位人口都有岗位、士气、住房。

### 职业

| 职业 | 主要产出 | 消耗 | 特点 |
| --- | --- | --- | --- |
| 能源工 | 能源 + | 食物 | 基础岗位，缺电时优先 |
| 矿工 | 矿物 + | 食物、能源 | 矿场等级越高越需要 |
| 农民 | 食物 + | 能源 | 人口越多越需要 |
| 工人 | 合金 + | 食物、矿物 | 工厂岗位 |
| 学者 | 科研 + | 食物、能源 | 实验室岗位 |
| 士兵 | 舰队 / 陆军 + | 食物、合金 | 军营岗位 |
| 后勤 | 仓储、补给、殖民效率 | 食物 | 中后期重要 |

### 分配方式

- **自动分配**：按玩家设定的优先级自动填岗。
- **手动锁定**：锁住关键岗位，自动分配不会动。
- **一键重排**：按当前建筑和舰队需求重新分配，有 30 秒冷却。

默认优先级：能源 → 食物 → 矿物 → 合金 → 科研 → 军事 → 后勤。
玩家可以拖拽调整，也可以点「均衡」。

### 士气

士气 0–100，全帝国共享一个基础值，各殖民地有局部修正。

| 因素 | 影响 |
| --- | --- |
| 食物充足 | +10 |
| 住房充足 | +5 |
| 战争状态 | -10 |
| 舰队战败 | -15（短期） |
| 背刺他人 | -20（全房间可见） |
| 奇观完成 | +10 |
| 静默者危机 | -5/波 |

| 士气 | 效果 |
| --- | --- |
| 80–100 | 产出 +15%，人口增长 +20% |
| 50–79 | 正常 |
| 30–49 | 产出 -10%，人口增长停滞 |
| 10–29 | 产出 -25%，有概率罢工 |
| 0–9 | 产出 -50%，殖民地可能叛乱 |

### 人口增长

- 逻辑斯蒂增长：越接近住房上限，增长越慢。
- 食物为负时，人口先停止增长，再缓慢下降。
- 战争、瘟疫、殖民会消耗人口。
- 人口低于 3 时，帝国进入「濒危」状态，产出大幅下降，但不会立刻出局。

### 开局：平民

所有人加入时空时：

- 12 人口，全部未分配。
- 1 座首都居住舱。
- 1 级电站、1 级矿场、1 级农场。
- 60 能源、90 矿物、40 食物、30 合金。
- 0 科研、0 影响力、0 星际代币、0 稀有资源。
- 10 艘护卫舰（基础巡逻队）。

没有任何隐藏加成。阵营、出生点、资源全部一致。

### 阵营：平民之后的第一次选择

第 10 分钟左右，玩家选择一条治国路线。
阵营不是开局加成，而是**一套独特的操作机制 + 一个明确的代价**。
选择后本局锁定，不能洗点。

| 阵营 | 核心机制 | 主动能力 | 代价 | 贸易/探险联动 |
| --- | --- | --- | --- | --- |
| 拓荒议会 | 公共契约：发布一个全房间可见的目标，所有玩家都能贡献 | 「号召」：15 分钟内全房间防御 +15% | 契约失败，全房间士气 -10 | 护航合同 +20% ST；探险队防御 +10% |
| 铁砧工业 | 过载生产：合金 +30%，可以把矿物直接转成合金 | 「超载」：10 分钟合金 +50%，之后 10 分钟 -20% | 食物和能源消耗 +15%，污染事件概率上升 | 舰船模块成本 -15%；探险损失修复 -20% |
| 星海教团 | 异常研究：遗迹和异常点产出更高，可以赌随机科技 | 「聆听」：揭示一个随机异常，选择风险/回报 | 能源产出波动 ±20%，事件风险更高 | 探险稀有资源 +20%；科研船成本 -20% |
| 自由商盟 | 黑市网络：可以和其他玩家交易资源、购买情报 | 「报价」：用 ST 买任意资源，或买一个扇区的视野 | 军事生产 -10%，契约和外交成本 +20% | 黑市 9 折；贸易合同 +20% ST |

阵营只改变「怎么玩」，不改变「起跑线」。
四个阵营的初始资源、人口、建筑完全一致。

## 六、科研系统

### 四条分支

| 分支 | 主题 | 代表科技 |
| --- | --- | --- |
| 能源 | 发电、储能、护盾 | 聚变堆、超导电网、偏导护盾 |
| 工业 | 采矿、制造、舰船 | 深层采矿、自动化工厂、模块化船坞 |
| 军事 | 武器、舰队、指挥 | 动能炮、导弹群、舰队协同 |
| 社会 | 人口、殖民、外交 | 住房改革、殖民适应、贸易公约 |

### 科技树结构

- 每条分支 5 层。
- 每层有两个互斥选项，选一个。
- 选错不能洗点，但下一层可以补另一条路线。
- 科技等级用 Tier 表示，Tier 越高，效果越强。
- 科技成本随 Tier 指数增长。

### 示例：第一层二选一

| 分支 | 选项 A | 选项 B |
| --- | --- | --- |
| 能源 | 聚变堆：能源产出 +25% | 超导电网：能源损耗 -30% |
| 工业 | 深层采矿：矿物产出 +20% | 自动化工厂：合金产出 +15%，人口需求 -10% |
| 军事 | 动能炮：舰队攻击 +15% | 导弹群：舰队首轮伤害 +30% |
| 社会 | 住房改革：人口上限 +20% | 殖民适应：殖民地成本 -15% |

### 科研卡片

每个时代开始时，玩家从 3 张随机科研卡中选 1 张，立即生效。

示例：

- **逆向工程**：立即获得 100 科研，所有科技成本 -5%。
- **战时经济**：合金产出 +30%，持续 5 分钟；食物消耗 +20%。
- **人口迁入**：立即获得 5 人口，士气 -5。
- **轨道电梯**：首都仓储上限 +50%。
- **黑市网络**：立即获得 200 ST；本局黑市 9 折。

科研卡不占科技树，是「一次性甜点」，让玩家在长局中也有新的选择。

### 追赶机制

- 科技 Tier 落后全房间最高玩家 2 级以上时，研究成本 -25%。
- 落后 3 级以上时，额外获得「逆向工程」事件。
- 不直接送科技，只给折扣和机会。

## 七、制造系统

### 生产链

```
矿物 ──→ 工厂 ──→ 合金 ──→ 舰船模块 / 建筑构件 / 殖民地套件
          ↑
        能源
```

### 工厂产线

工厂有 3 条产线，每条产线可以选择一个配方：

| 配方 | 输入 | 输出 | 用途 |
| --- | --- | --- | --- |
| 合金 | 矿物 + 能源 | 合金 | 通用材料 |
| 舰船模块 | 合金 + 能源 | 舰船模块 | 造船 |
| 建筑构件 | 合金 + 矿物 | 建筑构件 | 加速建造 |

### 生产模式

每条产线可以切换：

- **量产**：速度 +20%，质量 -10%。
- **精工**：速度 -20%，质量 +15%。
- **均衡**：无修正。

质量影响舰船模块的属性和建筑构件的耐久。
玩家可以在「快速爆兵」和「精品舰队」之间选。

### 舰船模块

舰船不再是单纯的「舰队点数」，而是由模块组成：

| 模块槽 | 选项 | 作用 |
| --- | --- | --- |
| 船体 | 护卫 / 巡洋 / 母舰 | 决定基础血量和载重 |
| 武器 | 动能 / 能量 / 导弹 | 克制不同防御 |
| 防御 | 护盾 / 装甲 / 点防 | 对抗不同武器 |
| 辅助 | 维修 / 侦察 / 运输 / 殖民 | 提供功能与续航 |

玩家在「制造」页保存 3 套蓝图，造船时选一套。
蓝图可以随时改，但改完要重新生产模块。

### 制造队列

- 所有制造都可以排队。
- 队列最多 10 项。
- 离线托管时，队列按当前配方继续生产。
- 队列空时，工厂自动生产合金，不浪费产能。

### 瓶颈提示

制造页顶部显示当前瓶颈：

- 「缺矿物」→ 建议升级矿场或贸易。
- 「缺能源」→ 建议建电站或关停低效产线。
- 「缺合金」→ 建议切换配方或拆船。
- 「缺人口」→ 建议住房或殖民。

不弹窗，只用一行小字。

## 八、军队系统

> 参考《星际争霸》的核心不是「操作快」，而是：
> **侦察 → 判断对方兵种 → 出克制兵种 → 用经济撑住交换。**
>
> 本作不控制单船，也不框选微操。
> 玩家控制的是：**编成、阵型、目标优先级、战术姿态、开战时机。**

### 8.1 三层舰队结构

舰队分三层，每层有自己的职责：

| 层级 | 作用 | 代表兵种 |
| --- | --- | --- |
| 舰载机层 | 侦察、制空、反主力舰、偷袭 | 侦察机、截击机、轰炸机、隐形机 |
| 主力舰层 | 正面交战、扛线、压制 | 护卫舰、驱逐舰、巡洋舰、战列舰、航母 |
| 支援层 | 维修、干扰、科研、运输、登陆 | 维修舰、电子舰、科研船、运输舰 |

一艘船不是「一个数字」，而是「一个兵种 + 一套模块 + 一个老兵等级」。
舰队战力由舰船数量、兵种、模块、老兵和指挥官共同决定，用于维护费、事件结算和最终评分。
殖民船不是独立战斗兵种，而是「运输舰 + 殖民模块」的配置，不参与克制环。
陆军是装载在运输舰里的地面单位，不单独占舰队兵种。
基础舰队上限 20 艘；军事区、轨道船坞和军事科技可以提高上限。

### 8.2 兵种表

| 兵种 | 层级 | 定位 | 克制 / 强项 | 弱点 / 被克 | 造价 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 侦察机 | 舰载机 | 视野、反隐、诱饵 | 隐形机、运输舰 | 截击机、护卫舰 | 低 | 不参战也能提供情报 |
| 截击机 | 舰载机 | 制空、反轰炸 | 轰炸机、隐形机、运输舰 | 护卫舰、电子舰 | 低 | 便宜、量大、怕点防 |
| 轰炸机 | 舰载机 | 反主力舰、反建筑 | 战列舰、航母、要塞 | 截击机、护卫舰 | 中 | 需要护航，单独出动就是送 |
| 隐形机 | 舰载机 | 偷袭后排、断补给 | 航母、运输舰、战列舰 | 侦察机、电子舰、截击机 | 高 | 需要反隐才能有效对抗 |
| 护卫舰 | 主力舰 | 护航、反战机、点防 | 截击机、轰炸机、隐形机 | 驱逐舰、巡洋舰 | 低 | 舰队的「防空网」 |
| 驱逐舰 | 主力舰 | 反护卫、反潜、机动 | 护卫舰、隐形机、运输舰 | 巡洋舰、战列舰 | 中 | 万金油，克制小船 |
| 巡洋舰 | 主力舰 | 正面主力、持续输出 | 驱逐舰、护卫舰 | 战列舰、轰炸机 | 中高 | 中期舰队的骨架 |
| 战列舰 | 主力舰 | 重炮、攻坚、扛线 | 巡洋舰、要塞、固定防御 | 轰炸机、隐形机、电子舰 | 高 | 慢，怕被风筝和集火 |
| 航母 | 主力舰 | 远程投送、持续制空 | 驱逐舰、巡洋舰（靠舰载机） | 轰炸机、电子舰、防空 | 高 | 需要护卫舰保护 |
| 电子舰 | 支援 | 干扰、反隐、削护盾 | 航母、战列舰、隐形机 | 截击机、护卫舰 | 中 | 不输出，但能让对方输出减半 |
| 科研船 | 支援 | 探索、考古、异常分析 | 遗迹、异常（提高收益） | 所有战斗单位 | 中 | 被击毁会丢失数据；探险核心 |
| 维修舰 | 支援 | 修复、护盾、续航 | 消耗战、持久战 | 轰炸机、隐形机 | 中 | 怕爆发，怕被切后排 |
| 运输舰 | 支援 | 掠夺、殖民、登陆 | 无 | 截击机、护卫舰、侦察机 | 低 | 掠夺和占领的必需品 |

### 8.3 克制环

基础克制环：

```
截击机 → 轰炸机 → 战列舰 → 巡洋舰 → 驱逐舰 → 护卫舰 → 截击机
```

辅助克制：

```
侦察机 / 电子舰  →  隐形机
轰炸机           →  航母 / 要塞 / 建筑
截击机           →  轰炸机 / 隐形机 / 运输舰
护卫舰           →  截击机 / 轰炸机
驱逐舰           →  护卫舰 / 隐形机
巡洋舰           →  驱逐舰
战列舰           →  巡洋舰 / 固定防御
航母             →  驱逐舰 / 巡洋舰（靠舰载机）
维修舰           →  消耗战
电子舰           →  航母 / 战列舰 / 隐形机
```

没有「万能兵种」。
战列舰怕轰炸机，轰炸机怕截击机，截击机怕护卫舰，护卫舰怕驱逐舰，驱逐舰怕巡洋舰，巡洋舰怕战列舰。
支援舰不参与基础克制环，但它们有各自的克制关系，能让克制环倾斜。

### 8.4 侦察与信息

参考星际争霸：**不知道对方出什么，兵力再多也可能白给。**

- 星区有战争迷雾；未侦察的扇区只显示「未知舰队」和大致规模。
- 侦察机、电子舰、侦察科技可以提供敌方编成情报。
- 没有反隐时，隐形舰不会被自动锁定；舰队会浪费火力。
- 情报有误差：
  - 无侦察：只知道「小 / 中 / 大」。
  - 侦察机：知道兵种大类，误差 ±1 级。
  - 电子舰 + 侦察科技：知道精确编成和阵型。
- 侦察机可以被击落；派侦察机要护航。
- 开战前可以花 10 秒「战前侦察」，成功率取决于侦察力量对比。

这让「先侦察再出兵」成为真正的决策，而不是无脑爆兵。

### 8.5 编成、阵型与战术

#### 舰队蓝图

玩家保存 3 套舰队蓝图，每套蓝图包含：

- 前排：护卫舰、驱逐舰、战列舰。
- 中排：巡洋舰、航母。
- 后排：侦察机、轰炸机、隐形机、电子舰、维修舰、运输舰。
- 每排的舰船数量受舰队上限限制。

#### 阵型

| 阵型 | 加成 | 惩罚 | 适合 |
| --- | --- | --- | --- |
| 线列 | 正面火力 +15% | 侧翼防御 -10% | 正面决战 |
| 楔形 | 首轮伤害 +20% | 持续作战 -10% | 突袭、抓落单 |
| 球形 | 防空/点防 +20% | 速度 -10% | 防轰炸、保护航母 |
| 分散 | 闪避 +20% | 指挥效率 -15% | 防 AOE、打游击 |

#### 战术姿态

开战前选一个，战斗中不能改：

- **激进**：追击更远，伤害 +10%，撤退损失 +20%。
- **均衡**：无修正。
- **保守**：受损后自动后撤，伤害 -10%，保留更多舰队。
- **伏击**：只在有隐形/小行星/星云时可用，首轮暴击，失败则被包围。

#### 目标优先级

自动战斗会按优先级选目标：

- 优先主力舰。
- 优先支援舰。
- 优先运输舰。
- 优先建筑/要塞。
- 优先航母/轰炸机。

选错优先级，可能出现「战列舰追着侦察机打」的尴尬场面。
这是玩家在 30 秒内能做出的、有意义的战术选择。

### 8.6 战斗流程

战斗分 5 个阶段，总共 15–30 秒：

1. **侦察**：反隐、锁定、计算情报差。
2. **接敌**：阵型、先手、伏击、战斗宽度。
3. **交锋**：3–5 轮，每轮计算火力、克制、护盾/装甲、暴击、损失。
4. **追击**：胜方追击，败方撤退；机动高的舰队损失更少。
5. **收尾**：战利品、残骸、老兵经验、战报。

#### 战斗宽度

航道有宽有窄：

- 窄航道：只有前排能接战，小船可以卡住大舰队。
- 宽航道：全舰队展开，火力优势放大。
- 要塞/小行星带：防守方获得宽度优势。

这是星际争霸「路口」的太空版：
**一支小舰队在窄航道里可以拖住大舰队，给主力争取时间。**

#### 战损与老兵

- 舰船被击毁后留下残骸，可以打捞合金。
- 存活舰船获得老兵等级：新兵 → 老兵 → 精锐 → 王牌。
- 老兵等级提升伤害、命中和撤退成功率。
- 王牌舰队被击毁时，全帝国士气 -10。
- 不搞「舰船永久死亡」的挫败感：主力舰可以花资源重建，但老兵等级回不来。

### 8.7 指挥官与旗舰

- 每支舰队有一个指挥官，以及一个指挥位（巡洋舰 / 航母 / 旗舰）。
- 指挥位是舰队核心，被击毁会让全舰队士气下降。
- 旗舰级指挥舰需要星核建造，提供舰队光环；没有旗舰时，由巡洋舰代行指挥。
- 指挥官有 1 个被动特质和 1 个每场战斗一次的主动技能。

| 指挥官 | 被动 | 主动 |
| --- | --- | --- |
| 战列线 | 主力舰伤害 +10% | 「齐射」：首轮伤害 +50% |
| 游击 | 机动 +15% | 「脱离」：撤退损失 -50% |
| 护航 | 防空 +15% | 「护盾」：3 秒内拦截轰炸 |
| 后勤 | 维护费 -10% | 「急修」：修复 20% 战损 |
| 侦察 | 情报误差 -1 级 | 「扫描」：暴露敌方后排 |
| 电子 | 干扰 +15% | 「静默」：敌方指挥 -30% 持续一轮 |

指挥官通过战斗、事件、殖民获得。
不抽卡，不氪金，不随机开箱。

### 8.8 维护、补给与战争疲劳

- 舰队维护费 = 舰队战力 × 0.02 / 分钟，吃食物和合金。
- 舰队必须在补给范围内作战；超出范围，维护费 +50%，伤害 -20%。
- 补给线可以被掠夺、封锁、切断。
- 连续作战会积累「战争疲劳」：士气下降，维护费上升。
- 付不起维护费，舰队会逃兵；逃兵变成中立海盗，可能去抢别人的贸易线。
- 这是一个负反馈：**爆兵太多，养不起，反而给邻居送敌人。**

### 8.9 兵种科技

兵种不是造出来就完事，还有升级路线：

| Tier | 解锁 | 示例升级 |
| --- | --- | --- |
| 1 | 侦察机、截击机、护卫舰、运输舰、科研船 | 侦察范围 +1；截击机速度 +20% |
| 2 | 轰炸机、驱逐舰、维修舰 | 轰炸机对主力舰 +25%；维修舰修复 +30% |
| 3 | 巡洋舰、隐形机、电子舰 | 巡洋舰射程 +1；隐形机反隐难度 +1 |
| 4 | 战列舰、航母 | 战列舰重炮 +20%；航母舰载机 +1 队 |
| 5 | 旗舰、超级武器 | 旗舰光环；轨道炮/行星护盾 |

每条军事科技仍然二选一。
例如 Tier 2 选「穿甲弹」还是「蜂群战术」：

- 穿甲弹：轰炸机/战列舰对主力舰 +25%。
- 蜂群战术：截击机/护卫舰数量 +20%，但单船血量 -10%。

### 8.10 军队与贸易、掠夺、探险的联动

军队不是只用来打正面战争：

- **护航**：护卫舰/截击机保护贸易线，降低被劫掠概率。
- **掠夺**：运输舰 + 驱逐舰/隐形机，抢资源、抢人口、拆船坞。
- **封锁**：巡洋舰/战列舰封锁航道，收关税或断补给。
- **反掠夺**：侦察机 + 截击机 + 护卫舰，抓隐形、追运输舰。
- **登陆**：运输舰 + 陆军，占领殖民地。
- **威慑**：把战列舰停在贸易线旁边，比真的开火更省钱。
- **远征**：指挥舰 + 科研船 + 护航舰，探索遗迹、异常和静默区边缘。

所以「军队复杂」不是为了打架更花哨，而是为了让贸易、掠夺、殖民、占领、探险都变成有兵种针对性的决策。

### 8.11 占领与运输

- **陆军**：由军营训练、占用人口；装载在运输舰里，不单独计入舰队兵种。
- **劫掠**：不需要陆军，抢了就走，获得资源，不占控制度。
- **占领**：需要运输舰和陆军，控制度涨得慢，但长期收益高。
- **解放**：把被占领的殖民地还给原主，获得大量影响力，但得罪占领者。
- **绑架**：隐形机/运输舰可以抓走对方人口或指挥官，换取赎金。
- **拆船坞**：轰炸机可以摧毁船坞，降低对方造船能力，但拿不到资源。

### 8.12 战斗 UX

- 战前：选择舰队、阵型、姿态、目标优先级。
- 战中：只显示阶段和战报，不需要微操。
- 战后：显示克制明细：
  - 「你的轰炸机打了 42% 伤害。」
  - 「对方的护卫舰拦截了 60% 的轰炸。」
  - 「你的隐形机被侦察机发现。」
- 战报让玩家下一局知道该造什么，而不是被一句「你输了」打发。

## 九、殖民系统

### 星区地图

- 每局 12–16 个扇区。
- 每个扇区有 1–3 颗星球。
- 扇区之间有航道，航道决定补给线和进攻路线。
- 地图不是 3D，而是「扇区卡片 + 航道列表」。

### 星球类型

| 类型 | 资源倾向 | 特殊 |
| --- | --- | --- |
| 岩石 | 矿物 + | 建筑成本低 |
| 海洋 | 食物 + | 人口上限高 |
| 气态 | 能源 + | 需要特殊科技 |
| 冰封 | 科研 + | 防御高，人口低 |
| 遗迹 | 科研 ++ | 随机事件，危险 |
| 熔岩 | 合金 + | 环境恶劣，人口消耗 |
| 花园 | 全能 | 稀有，必争 |

### 殖民条件

- 需要殖民船（合金 + 食物 + 人口）。
- 必须在补给范围内：从首都或已有殖民地沿航道连接。
- 超出补给范围：殖民地效率 -50%，士气 -20，可能叛乱。
- 中立扇区可能有海盗或静默者前哨，需要先清掉。

### 殖民地等级

| 等级 | 名称 | 槽位 | 解锁 |
| --- | --- | --- | --- |
| 1 | 前哨 | 1 | 基础采集 |
| 2 | 定居点 | 2 | 工厂/实验室 |
| 3 | 城市 | 3 | 舰船厂/防御 |
| 4 | 星区首府 | 4 | 奇观/行政 |
| 5 | 生态城 | 5 | 终极建筑 |

### 区域（District）

每个殖民地槽位可以建一个区域：

- 能源区：能源产出 +20%/级。
- 矿业区：矿物产出 +20%/级。
- 农业区：食物产出 +20%/级。
- 工业区：合金产出 +20%/级。
- 科研区：科研产出 +20%/级。
- 军事区：舰队上限 +5/级，防御 +15%/级。
- 文化区：影响力 +2/分钟/级，士气 +10/级。
- 港口区：贸易容量 +20%/级；3 级时补给范围 +1。

区域可以升级，但每个殖民地最多 5 个槽位。
玩家必须在「专业化」和「自给自足」之间选。

### 殖民地特质

每颗星球随机 1–2 个特质：

- 富矿：矿物 +30%。
- 沃土：食物 +30%。
- 科研遗迹：科研 +20%，事件概率 +15%。
- 潮汐锁定：能源 +20%，人口上限 -10%。
- 有毒大气：人口增长 -20%，合金 +20%。
- 古代轨道：防御 +30%，可修复。

特质让每颗星球不一样，避免「无脑占最大」。

## 十、占领、贸易、掠夺、探险与外交

### 三种目标

| 目标 | 说明 | 收益 | 风险 |
| --- | --- | --- | --- |
| 中立扇区 | 海盗、静默者前哨 | 资源、航道、殖民点 | 防御损失 |
| 玩家扇区 | 其他领主的殖民地 | 资源、控制度、打击对手 | 对方报复、全房间仇视 |
| 静默者节点 | 终局危机目标 | 危机值下降、稀有科技 | 高难度战斗 |

### 控制度

- 每个扇区有 0–100 的控制度。
- 占领后控制度从 0 开始，每 10 秒 +1（有驻军时 +2）。
- 控制度达到 100 才算完全控制。
- 控制度低于 30 时，资源收益减半。
- 原主可以发动「解放」，降低控制度。

### 驻军

- 占领需要驻军，驻军占用舰队上限。
- 驻军越多，控制度涨得越快，但维护费越高。
- 驻军不足，抵抗度上升，可能爆发叛乱。

### 抵抗度

- 抵抗度 0–100，占领后每 10 分钟 +1。
- 抵抗度高时，资源收益下降，事件概率上升。
- 可以通过「安抚」（消耗影响力）或「镇压」（消耗舰队战力）降低。
- 镇压会降低全房间士气，并留下「暴君」标记。

### 首都陷落

- 首都陷落不等于出局；只要还保有舰队或殖民地，玩家就变成「流亡者」。
- 流亡者保留现有舰队，并获得一座移动母舰。
- 流亡者可以继续战斗、支援别人、或者等待机会夺回首都。
- 流亡者不能殖民，但可以占领、劫掠、贸易、外交。

### 贸易

贸易是「不打架也能赢」的路线，也是掠夺者的猎物。
它用星际代币结算，用贸易路线生产，用护航和保险续命。

> 当前原型已实现：4 种资源的即时买卖（每 15 分钟相位刷新，无手续费/挂单）、每人 3 份合同、每人 3 件黑市库存。贸易路线、护航、保险、关税、封锁、走私和全房间共享黑市仍是目标设计。

#### 星际代币（ST）

- **唯一货币**：星际代币是本作唯一的「钱」，不占普通仓储，存放在国库。
- **不能生产**：没有任何建筑能直接产出 ST，只能通过交易和冒险获得。
- **来源**：市场卖资源、贸易路线、合同赏金、关税、掠夺商队/仓库、探险打捞、悬赏。
- **消耗**：黑市购物、雇佣兵/护航佣金、保险、赎金、赔款、政治献金、合同保证金。
- **价格是活的**：战争、封锁、危机、信誉都会影响黑市报价和合同赏金。
- **会被抢**：国库可被掠夺最多 10%，需要运输舰；殖民地仓库被攻破也会损失税金。
- **不计入霸业值**：经济胜利看累计贸易收入，不看当前钱包余额。
- **不跨局**：不能充值、不能提现、不能继承；关房即焚。
- **不换现实货币**：玩家之间可以用 ST 签合同、付佣金，但不能现金交易。

#### 市场

- 用**星际代币（ST）**买卖资源。
- 每 15 分钟刷新一次价格。
- 玩家可以挂买单/卖单：用 ST 买资源，或卖资源换 ST。
- 价格受全房间供需影响：战争、封锁、危机都会推高食物和合金。
- 每笔交易收 5% 手续费，以 ST 结算。
- 市场只显示最近成交价，不显示谁的订单，避免被精准狙击。

#### 贸易路线

- 连接自己的两座殖民地，或与其他玩家签订贸易协定。
- 每条路线每分钟产出资源，并额外产出少量星际代币。
- 路线有容量，容量由港口区、运输舰、科技决定。
- 路线可以被封锁、劫掠、切断。
- 贸易路线越肥，越需要护航；护航越强，越值得被抢。

#### 合同

- 其他玩家或中立势力发布合同，赏金用星际代币结算：
  - 「送 200 食物到 X，赏 150 ST。」
  - 「保护我的贸易线 30 分钟，赏 100 ST。」
  - 「摧毁 Y 的船坞，赏 300 ST。」
- 完成获得 ST、影响力、信誉。
- 违约或超时，失去信誉，合同方可以悬赏你。
- 玩家之间可以用 ST 支付雇佣、赔款、赎金、保护费。

#### 关税与封锁

- 控制航道可以设关税：每艘经过的贸易船抽 10%，以 ST 结算。
- 关税过高，别人会绕路或组队打你。
- 战列舰/巡洋舰可以封锁航道，切断补给和贸易。
- 封锁是一种战争行为，会留下「挑衅」标记。

#### 走私

- 黑市买卖稀有科技、人口、舰船模块、违禁品，全部用 ST 结算。
- 收益高，但被查获会损失货物 + 信誉。
- 自由商盟阵营有走私加成。
- 走私路线不显示在公开列表，只能通过黑市联系人发现。

#### 黑市

黑市是星际代币的主要出口，也是稀有资源的二级市场。

- **入口**：第一次接触赫卡忒后解锁；所有玩家都能进。
- **库存**：目标设计为全房间共享，每 15 分钟刷新，稀有商品 1–3 件，先到先得；当前原型是每人独立刷新 3 件。
- **商品**：
  - 稀有科技（直接解锁一条科技或科研卡）。
  - 独特舰船模块（黑市限定，不能自产）。
  - 稀有资源：遗物、星核、数据核心。
  - 星区情报：揭示一个扇区、舰队编成、贸易路线。
  - 雇佣兵合同：租用一支中立舰队若干分钟。
  - 探险坐标：高价值遗迹/异常点。
  - 赎金/保释：赎回被俘的指挥官或人口。
  - 洗白：花 ST 移除「海盗」标记（不能移除「失信」）。
  - 政治献金：用 ST 换影响力，汇率很差。
- **价格**：基础价 ±30% 波动；战争、封锁、危机 +20–50%；信誉好可以打 9 折，被赫卡忒拉黑则 +30%。
- **规则**：不赊账、不预订、不退款；库存买走就没了。
- **底线**：不能充值、不能提现、不能跨局继承、不卖数值抽卡。

#### 护航与保险

- 玩家可以雇佣其他玩家或自己的舰队护航，佣金用 ST 结算。
- 护航舰队会在贸易路线被劫掠时自动拦截。
- 可以向商盟购买贸易保险：被劫掠后赔付 50%，保费按风险用 ST 计算。
- 护航和保险让「贸易」不只是经济行为，也是军事和外交行为。

### 掠夺

掠夺是「用军队直接改写经济」的路线。
抢货物、抢税金、抢赎金，最后都能在黑市换成 ST。

星际代币存放在国库。
掠夺方最多抢走国库的 10%，需要运输舰；国库越满，越容易招贼。

#### 掠夺目标

| 目标 | 需要 | 收益 | 代价 |
| --- | --- | --- | --- |
| 贸易船队 | 隐形机/驱逐舰/运输舰 | 货物、ST、影响力 | 被护航舰队拦截 |
| 殖民地仓库 | 轰炸机 + 运输舰 | 资源、人口、税金 ST | 抵抗度上升、对方报复 |
| 船坞 | 轰炸机 | 降低对方造船能力 | 拿不到资源，结仇 |
| 奇观工地 | 轰炸机 + 运输舰 | 破坏奇观进度，抢构件 | 全房间关注 |
| 补给线 | 巡洋舰/隐形机 | 断补给、降士气 | 需要持续驻守 |
| 指挥官 | 隐形机 + 运输舰 | 赎金 ST、敌方士气 -10 | 高难度、可能被反杀 |

#### 掠夺方式

- **快袭**：抢完就走，60 秒追击窗口；机动高、隐形高更容易逃脱；抢到的货物可以在黑市洗成 ST。
- **占领**：带陆军和运输舰，长期控制；收益高，但会被反推。
- **绑票**：抓走指挥官/人口，换取 ST 赎金；不占控制度，但结仇深。
- **拆家**：摧毁船坞/奇观/仓库，降低对方长期能力；拿不到资源，但能拖慢对手。
- **封锁**：不抢，只断；用舰队堵航道，收关税或逼对方谈判。

#### 追击与反掠夺

- 掠夺后进入「追击」状态，防守方可以派机动舰队拦截。
- 侦察机/截击机克制隐形机和运输舰；护卫舰克制轰炸机。
- 防守方可以设「诱饵船」：看起来是贸易船，实际是护航舰队。
- 分散仓储、隐藏仓库、地下堡垒可以降低被抢损失。
- 被劫掠后可以悬赏掠夺者；其他玩家可以接单。

#### 私掠与信誉

- **私掠许可证**：商盟/议会发放，允许合法劫掠特定目标；被劫掠者无法获得全房间同情。
- **海盗**：无差别劫掠，所有贸易路线都可能被拉黑，所有人可以围剿。
- **义商**：护航、履约、救灾，获得贸易折扣和护航优先权。
- **暴君**：镇压、毁约、拆平民区，外交成本上升，容易被围剿。
- 信誉不是道德分数，是**别人愿不愿意跟你做生意、愿不愿意救你**。

### 探险

探险是「用军队赌稀有资源」的路线。
它不占核心循环的主线，但决定了你能否造旗舰、星门和超级武器。

#### 远征队编组

- 在「舰队」页的「远征」子页编组，最多同时派出 3 支远征队。
- 每支远征队从现有舰队中抽船，出发期间不能参加主舰队战斗。
- 推荐编成：
  - 1 艘指挥舰（旗舰/巡洋舰）。
  - 1–2 艘侦察/科研舰（侦察机、科研船、电子舰）。
  - 2–4 艘护航舰（护卫舰、驱逐舰、截击机）。
  - 1–2 艘运输舰（装战利品）。
  - 可选：维修舰、隐形机、轰炸机。
- 远征队必须有补给：食物、合金、ST。
- 可以指派指挥官，指挥官技能在探险事件中生效。
- 远征队有独立容量，受「远征科技」和舰队上限限制。

#### 风险姿态

| 姿态 | 战利品 | 损失风险 | 适合 |
| --- | --- | --- | --- |
| 谨慎 | -20% | -30% | 新手、缺船、只想拿保底 |
| 均衡 | 无修正 | 无修正 | 默认 |
| 深入 | +30% | +50% | 赌稀有资源、赌剧情 |
| 拾荒 | +10% ST | +10% | 专门去战场/残骸捡垃圾 |

#### 目的地

| 目的地 | 风险 | 主要产出 | 特殊 |
| --- | --- | --- | --- |
| 未探索扇区 | 低 | 地图情报、殖民点、少量资源 | 稳定、适合前期 |
| 遗迹带 | 中 | 遗物、数据核心、科技 | 可能触发「回声」剧情 |
| 深空异常 | 高 | 星核、稀有科技、独特模块 | 可能损失科研船 |
| 漂流方舟 | 中高 | 数据核心、人口、科技 | 与主线事件联动 |
| 静默区边缘 | 极高 | 星核、静默者弱点、危机线索 | 可能推进审计进度 |
| 裂谷潮汐 | 限时 | 大量 ST、稀有资源 | 只在特定时间窗口出现 |

#### 探险时长

- 10–60 分钟，按目的地和距离决定。
- 10–20 分钟：短途，保底，适合上班摸鱼。
- 20–40 分钟：标准，收益和风险平衡。
- 40–60 分钟：深空，高收益，可能全军覆没。
- 可以随时召回，但只拿到已探索部分的收益，且损失部分补给。
- 结算前 60 分钟停止派遣新远征队；未返航的远征队按已探索部分结算。

#### 结算

探险结果在出发时由房间种子决定，返航时才揭示，不能读档。

| 结果 | 概率 | 内容 |
| --- | --- | --- |
| 大成功 | 15% | 稀有资源 ×2、科技、独特模块、剧情碎片 |
| 成功 | 45% | 稀有资源 ×1、ST、地图情报、殖民点 |
| 部分成功 | 25% | 少量 ST/资源，损失 1–2 艘护航舰 |
| 失败 | 10% | 损失舰队、指挥官被俘、科研船数据丢失 |
| 灾难 | 5% | 远征队全灭，危机值 +5，首都士气 -10 |

#### 稀有资源的用途

| 稀有资源 | 用途 |
| --- | --- |
| 遗物 REL | 解锁稀有科技、建造奇观、打造独特舰船模块 |
| 星核 COR | 建造旗舰、超级武器、星门 |
| 数据核心 DATA | 解锁科技、揭示星图、推进「回声」剧情 |

#### 探险与贸易、掠夺的联动

- 黑市可以买「探险坐标」，直接刷出一个高价值目的地。
- 黑市可以卖稀有资源，换大量 ST。
- 探险队返航时可能被其他玩家伏击；战利品会被抢。
- 掠夺者可以专门蹲守遗迹带出口。
- 护航合同可以扩展到「护送探险队返航」。

#### 探险 UI

- 舰队页 `←` / `→` 切换到「远征」。
- 每支远征队显示：目的地、编成、风险姿态、预计时间、预计收益、预计损失。
- 出发只需 30 秒：选队伍 → 选目的地 → 选姿态 → 出发。
- 返航报告最多 3 行：
  - 「带回了 2 枚遗物和 1 个数据核心。」
  - 「损失 2 艘护卫舰，指挥官被俘。」
  - 「发现了一条通往静默区的航道。」

探险让「军队」不只是战争的工具，也是探索、考古、赌运气和讲故事的载体。

### 外交与战争

| 动作 | 消耗 | 效果 |
| --- | --- | --- |
| 互不侵犯 | 50 影响力 | 双方不能攻击，持续 30 分钟 |
| 贸易协定 | 100 影响力 | 双方资源交换 +20%，可建贸易路线，持续 60 分钟 |
| 开放边境 | 50 影响力 | 舰队和贸易船可以通过对方航道，持续 30 分钟 |
| 联合行动 | 150 影响力 | 共享视野，共同攻击一个目标，持续 60 分钟 |
| 宣战 | 50 影响力 | 正式战争，可以占领；无宣战劫掠会被标记为海盗 |
| 停战 | 100 影响力 | 结束战争，双方 30 分钟内不能互相攻击 |
| 赔款 | ST 或资源 | 战败方向胜利方支付，换取停战或释放殖民地 |
| 雇佣 | ST + 合同 | 雇佣其他玩家打一个目标；违约失去信誉 |
| 悬赏 | 100 影响力 + 赏金 ST | 给某个玩家挂赏金；任何人完成都能领取 |
| 赎回 | ST | 赎回被俘的指挥官、人口或运输船 |
| 政治献金 | ST | 用星际代币换影响力，汇率很差 |
| 背刺 | 无 | 立即攻击，获得「失信」标记，全房间可见 |

「失信」标记：

- 所有玩家看到你撕毁条约。
- 外交成本 +50%。
- 事件选项中出现「不信任你」的分支。
- 贸易价格变差，护航合同没人接。
- 不影响胜负，但影响别人愿不愿意跟你合作。

## 十一、开发系统

### 首都升级

- 首都等级 1–10。
- 每级解锁新建筑、新槽位、新仓储上限。
- 首都升级需要矿物 + 合金，后期需要影响力。
- 首都等级决定「时代」的解锁，但不强制推进时间。

### 殖民地开发（当前原型已部分实现）

- 每个殖民地等级 1–5；当前原型用等级直接提供产能、人口上限和舰队上限。
- 每个殖民地可以选择一种**定位**，共 8 种：均衡 / 能源 / 矿业 / 农业 / 工业 / 科研 / 贸易 / 要塞。
- 第一次选择定位免费；之后每次改定位消耗 10 影响力。
- 定位按殖民地等级叠加修正：

| 定位 | 加成 | 代价 |
| --- | --- | --- |
| 均衡 | 无 | 无 |
| 能源世界 | 能源 +9%/级 | 食物 -3%/级 |
| 矿业世界 | 矿物 +9%/级 | 能源 -2%/级 |
| 农业世界 | 食物 +9%/级 | 合金 -3%/级 |
| 工业世界 | 合金 +9%/级 | 食物 -3%/级 |
| 科研世界 | 科研 +9%/级 | 人口上限 -2%/级 |
| 贸易港 | 市场卖价 +2%/级、影响力 +4%/级 | 无直接代价 |
| 要塞世界 | 舰队上限 +4/级 | 无直接代价 |

- 多个同类殖民地按等级叠乘，但单项产出修正被限制在 0.5×–2.5×，避免极端堆叠。
- 槽位、区域建筑、殖民地特质和“全能源 / 全工业 / 全科研”式的极限专精仍是目标设计；当前原型用定位表替代。

### 目标设计：区域与专精

- 每个殖民地最多 5 个槽位，随殖民地等级解锁。
- 区域可以升级 1–3 级。
- 殖民地等级决定可用槽位数量。
- 目标中的专业化殖民地有更极端的加成：
  - 全能源：能源 +50%，其他 -20%。
  - 全工业：合金 +50%，食物 -20%。
  - 全科研：科研 +50%，人口 -20%。
  - 均衡：无加成，无惩罚。

### 奇观

每局从下列奇观中随机出现 3 个，先到先得。
奇观提供独特效果和大量霸业值。

> 当前协议 v6 实现 3 座奇观；下表 6 座是目标卡池，每局从中随机出现 3 座。

| 奇观 | 效果 | 造价 |
| --- | --- | --- |
| 戴森环 | 能源产出 +100% | 极高 |
| 星门 | 全星区补给范围 +1，舰队移动 +50% | 高 |
| 知识方舟 | 科研 +100%，科技成本 -20% | 高 |
| 轨道船坞 | 舰队上限 +50%，造船速度 +50% | 高 |
| 议会穹顶 | 影响力 +100%，外交成本 -50% | 中 |
| 生态乌托邦 | 人口上限 +50%，士气 +20 | 高 |

奇观建造期间全房间可见，其他人可以来打。
这创造了「保护奇观」和「阻止别人奇观」的战略目标。

### 星区改造

终局项目，消耗大量资源，改变整个星区：

- **星门网络**：所有玩家补给范围 +1。
- **气候稳定器**：所有殖民地食物 +20%。
- **静默屏障**：终局危机伤害 -20%。

改造项目通常是合作目标，也可以被个人独占。

## 十二、事件与危机

> 当前原型：11 张事件卡，每 90–180 秒触发一张，最多排队 4 条；下面的 10–15 分钟 / 8 条是目标设计。

### 个人事件

- 每 10–15 分钟触发一次。
- 最多排队 8 条。
- 超过 8 条，最旧的一条自动按「保守选项」结算。
- 事件不弹窗，只在面板里显示；任务栏控件轻微闪烁。
- 每个事件 2–3 个选项，没有明显正确答案。

### 全房间危机

- 每 30–45 分钟触发一次。
- 所有玩家看到同一个危机。
- 玩家可以选择贡献资源、舰队、科研。
- 贡献最多的人获得额外奖励；贡献最少的人受到惩罚。
- 危机处理失败，全房间受到减益。

### 全房间审计压力（当前原型已实现）

> 这是「全房间危机」的第一版落地，先把共享压力跑通，再扩展贡献与投票。

- 审计压力是**全房间共享**的 `0–100` 数值，开局为 15。
- 压力随房间时间和活跃人数缓慢上升；黑市交易、远征、奇观、攻击中立目标和玩家冲突会额外增加。
- 阈值 40 / 65 / 85 分别触发「采样 / 潮汐 / 归档」三档共享危机，对所有成员同时生效。
- 采样：损失少量能源和矿物，但每个成员获得 1 个数据核心。
- 潮汐：损失一部分舰队、食物和士气。
- 归档：损失科研、星际代币、舰队和士气；不直接淘汰玩家。
- 任意成员都可以在事件页消耗 **1 数据核心 + 40 能量**降 15 压力，或消耗 **30 能量**广播降 5 压力。降低的是全房间压力。
- 审计压力显示在联机页和事件页；危机触发时阿刻会留一句记录。
- 尚未实现：贡献排行榜、危机投票、个人奖励/惩罚、黑市拍卖。

### 黑市拍卖

- 第 120 分钟后，每 60 分钟可能触发一次。
- 赫卡忒拍卖一件稀有资源（遗物 / 星核 / 数据核心）。
- 全房间玩家暗标 ST，出价最高者获得，输家保留 ST。
- 同价重拍一次；再同价流拍，物品进入下次黑市。
- 不显示输家的出价，只显示赢家和成交价。

黑市拍卖是星际代币最刺激的出口：
你可能用一半国库买到一个星核，也可能什么都没买到，但让对手花光了钱。

### 终局危机：静默者

- 第 4 小时（240 分钟）开始，审计进度条出现。
- 进度条 0–100%。
- **危机值就是审计进度条的百分比**；前期隐藏累计，第 4 小时后显示。事件里的 +5 / -10 直接加减进度。
- 第 4 小时前危机值最高累计到 60；第 4 小时后解除上限。
- 玩家每丢一座殖民地 +5%，每击退一波 -10%。
- 进度条到 100%，全房间失败。
- 玩家可以提交「自治申请」自保，但会加快其他人的进度。
- 合作防守成功，触发「共治结局」。

### 事件设计原则

1. **没有免费午餐。** 每个选项都有代价。
2. **代价类型不同。** 有的花资源，有的花人口，有的花士气，有的花外交。
3. **后果可预期但不完全确定。** 50% 概率的事件，要明确写出来。
4. **不惩罚挂机。** 自动结算永远选保守选项。
5. **不制造死局。** 任何事件都不应该让玩家直接失去游戏。

## 十三、指令卡

为了让玩家每隔几分钟有一次「主动操作」，加入「领主指令卡」。

- 每 15 分钟出现一次。
- 3 张卡选 1 张，120 秒内有效，不选就消失。
- 不占科技树，不占建筑队列。
- 刷新相位全房间同步，但每人抽到的三张不同；选择互不影响。

### 示例卡池

| 卡牌 | 效果 | 代价 |
| --- | --- | --- |
| 紧急征召 | 立即获得 5 艘护卫舰 | 人口 -3，士气 -10 |
| 科研突破 | 立即获得 150 科研 | 能源 -100 |
| 殖民补贴 | 下一次殖民成本 -50% | 食物 -100 |
| 黑市采购 | 立即获得 100 单位任意资源 | 花费 200 ST |
| 紧急贷款 | 立即获得 300 ST | 10 分钟后还 400 ST；不还则信誉 -1 |
| 遗迹坐标 | 立即刷新一个高价值探险点 | 支付 200 ST 或影响力 |
| 外交斡旋 | 立即获得 100 影响力 | 合金 -100 |
| 坚壁清野 | 所有殖民地防御 +30%，持续 15 分钟 | 资源产出 -20% |
| 轨道轰炸 | 对目标扇区造成伤害 | 全房间可见「暴君」标记 |
| 人才引进 | 立即获得 3 人口 | 科研 -50 |
| 战时经济 | 合金 +50%，持续 10 分钟 | 食物 -30% |
| 静默监听 | 获得静默者弱点，危机值 +5 | 无 |

指令卡是「甜点」，不是「主菜」。
它的作用是让玩家在等待资源时有事可做，而不是取代主循环。

## 十四、胜负与评分

### 霸业值

结算分数，实时显示在面板顶部。

```
霸业值 =
    人口 × 2
  + 殖民地等级总和 × 15
  + 占领扇区数 × 25
  + 科技 Tier 总和 × 20
  + 舰队战力 × 0.5
  + 奇观数 × 50
  + 危机贡献 × 0.2
  + 契约完成数 × 10
  + 特殊成就 × 25
```

危机贡献 = 你在全房间危机中投入的资源、舰队和科研折算成的贡献值。

星际代币不计入霸业值。
经济胜利看的是**累计贸易收入**，不是当前钱包里囤了多少 ST。

### 胜利条件

| 条件 | 说明 |
| --- | --- |
| 标准胜利 | 6 小时结束时，霸业值最高 |
| 支配胜利 | 控制 60% 扇区，并保持 5 分钟 |
| 共治胜利 | 全房间存活，审计进度清零，且联合防线贡献达标 |
| 经济胜利 | 累计贸易收入 + 影响力第一，且没有发动大规模战争 |
| 军事胜利 | 舰队战力第一，且占领首都数最多 |

如果同时满足多个条件，按「共治 → 支配 → 军事 → 经济 → 标准」的顺序结算。

### 失败条件

| 条件 | 说明 |
| --- | --- |
| 审计失败 | 审计进度条 100%，全房间失败 |
| 个人出局 | 首都陷落但仍保有舰队或殖民地 → 流亡者；流亡者再失败，或首都陷落且一无所有 → 观战 |
| 主动投降 | 玩家可以投降，保留结算分数，不保留帝国 |

### 结算界面

- 先展示房间结局（共治 / 霸主 / 铁与火 / 商路 / 归档）。
- 再展示个人霸业值排名。
- 再展示三个「高光时刻」：
  - 最大单场战斗胜利。
  - 最远一次探险 / 最稀有战利品。
  - 最贵奇观。
- 最后展示「下一局」按钮。

不展示「充值」「成长」「通行证」。
这局结束，一切归零。

## 十五、单机、离线与托管

### 当前原型（协议 v6）

单机 / 自建服务器模式：

- 本地存档。
- 适合挂机和熟悉玩法。
- 不参与联机排名。

联机模式：

- 服务端持续按正常速率推进所有成员，包括离线成员；当前没有 50% 效率的托管 AI。
- 离线玩家不会自动建造、攻击、签合同、买黑市、派远征或处理事件；已出发的远征照常返航。
- 主动退出会保留存档 30 分钟；同一玩家 ID + 房间码回来即可恢复原帝国。
- 未开局掉线保留 120 秒；对局中掉线但未主动退出的成员保留 15 分钟。
- 迟到的新玩家按已开局时间的 75% 追赶，最多补 30 分钟。
- 全员离线不自动暂停；房间从创建起最长存活 6 小时。
- 服务器进程退出，所有房间立即消失。

### 目标设计（尚未实现）

托管：

- 按玩家预设的方针运行：保守 / 均衡 / 扩张。
- 产出效率 50%。
- 不主动攻击玩家，不主动劫掠。
- 维持已有贸易路线，但不签新合同、不主动花 ST 买黑市。
- 不主动派远征队；已经出发的远征队按原计划返航。
- 事件自动选保守选项。
- 不建造奇观，不发动战争，不主动解散舰队。
- 玩家回来时看到一份「托管报告」。

全员离线与重连：

- 全员离线 60 秒后自动暂停，房间保留 10 分钟。
- 掉线后 5 分钟内快速重连；5–15 分钟完整重连并重放指令。
- 超过 15 分钟视为放弃本局，玩家转为观战。
- 主动退出与掉线同规则：15 分钟内可重连，超时转观战。
- 执事掉线后自动选举新执事（当前原型已实现自动迁移，但没有 tick 重放）。

## 十八、平衡原则

### 1. 反雪球

- 领先玩家维护费更高。
- 落后玩家获得「逆潮补给」：资源 +20%，科技折扣。
- 占领过多会触发「过度扩张」：抵抗度上升，维护费上升。
- 没有永久淘汰，流亡者可以复仇。

### 2. 反龟缩

- 静默者危机会逼所有人出兵。
- 奇观全房间可见，龟缩会被抢。
- 资源仓储有上限，囤积会浪费。
- 中立区有高价值目标，先到先得。

### 3. 反单一解

- 每种舰队编成都有克制。
- 每条科技路线都有短板。
- 每种阵营都有反制手段。
- 没有「最优开局」，只有「适合当前局势」。

### 4. 时间友好

- 战斗 15–30 秒内结束。
- 事件 30 秒内处理。
- 托管不会自杀。
- 离开半小时不会崩盘。

### 5. 社交有趣

- 背刺有代价，但收益高。
- 合作有奖励，但不强制。
- 契约公开，失信可见。
- 流亡者可以当雇佣兵、搅局者、复仇者。

### 6. 星际代币不失控

- ST 不能靠建筑生产，只能靠交易、掠夺、探险、悬赏获得。
- ST 的主要出口是黑市、雇佣、保险、赎金、政治献金。
- ST 不计入霸业值，鼓励花掉而不是囤积。
- 黑市库存全房间共享，稀有货先到先得，制造竞争。
- 没有真实货币入口，没有付费代币，没有抽卡。

### 7. 探险有风险

- 探险收益高，但损失真实：舰船、指挥官、科研船数据都可能丢。
- 远征队出发时确定结果，返航才揭示，联机不能读档。
- 稀有资源不能靠生产刷，只能探险、黑市、掠夺。
- 深空目的地必须有吸引力，但不能让一次失败直接终结整局。
- 托管不会主动派远征队，避免玩家离线时被赌死。

## 十九、MVP 与路线图

### M0：能玩

- 改名「星际领主」。
- 单机循环：资源、人口、科研、建筑、舰队、殖民、进攻。
- 房间：创建、加入、开始、离开；准备为预留。
- 统一平民开局。
- 联机数据不落盘；客户端内存 + 帧同步是目标架构，分阶段迁移（见 04）。
- 4 位房间码。

### M1：好玩

- 职业分配与士气。
