# 《星际领主》设计文档

> **一句话定位**
>
> 一款藏在 Windows 任务栏里的多人星际领主模拟游戏。
> 你以为自己在看 CPU 占用，其实整个星区正在你手里打成一锅粥。

| 项目 | 设定 |
| --- | --- |
| 产品名 | 星际领主 / Stellar Lord |
| 联机入口 | 加入时空 / Join the Rift |
| 类型 | 任务栏伪装 + 轻量放置 + 实时多人 4X |
| 平台 | Windows 10 / 11 |
| 人数 | 1–8 人，推荐 4 人 |
| 单局时长 | 快速 2 小时 / 标准 6 小时 / 朋友 6 小时 / 长局 12 小时 / 马拉松 24 小时 |
| 操作节奏 | 单次操作 30 秒内，随时可中断 |
| 核心循环 | 发展（资源）→ 人口 → 科研 → 制造 → 军队 → 殖民 → 占领 → 开发 |
| 横切玩法 | 玩家贸易、走私、护航、劫掠、掠夺、悬赏、舰队远征、星际代币与黑市 |

> **范围说明**
>
> 本文档里的「不落盘 / 只存内存」默认指**联机对局**。
> 单机模式保留本地存档，否则放置游戏无法成立；单机存档不参与联机，也不影响联机公平。

## 这一版到底改了什么

### 1. 从货运原型到「星际领主」

不再是被动等船到港的货运模拟，而是一个**从平民起步、抢星区、当霸主**的轻量 4X。

- 货运的「航线」保留为星区之间的**补给线**。
- 货运的「待办事件」升级为**个人事件 + 全房间危机**。
- 货运的「上市转生」取消，改成每局独立的**星区周期**：一局打完，文明归零，下局重新从平民开始。

### 2. 核心循环更清楚，每一步都有决策

```
发展（资源） → 人口 → 科研 → 制造 → 军队 → 殖民 → 占领 → 开发
      ↑                                                      │
      └──────────────────── 反哺 ────────────────────────────┘
```

不是「点一下升级」的无脑循环。每个节点都要做取舍：

- 资源：能源分给民用、科研还是军工？
- 人口：当工人、学者还是士兵？
- 科研：两条互斥路线选哪条？
- 制造：爆合金还是攒舰船模块？
- 军队：侦察、截击、轰炸、主力舰、支援舰怎么配？
- 殖民：占肥球还是抢航道？
- 占领：劫掠一波就走，还是长期占领？
- 贸易：卖资源赚差价，还是囤货等高价？
- 掠夺：抢商路、抢仓库，还是抢船坞？
- 探险：深入遗迹还是见好就收？
- 开发：堆经济、堆奇观，还是堆防御？

### 3. 联机改成「加入时空」

- 目标架构：服务器只做**房间撮合 + 消息转发**，不存对局数据、不写存档、不做权威模拟。
- 任何人都能创建房间，创建者是**初始执事**，不是老板。
- 执事掉线自动迁移，任何人接手都能继续。
- 所有人加入时统一初始化成**平民**：12 人口、一座居住舱、三座基础建筑，资源完全一致。
- 房间码 4 位，支持公开房间列表和私密房间。
- 执事点击开始，所有人统一进入游戏。
- 当前原型处于 **T0**：服务端内存持有 `GameState` 并权威结算；上面的「只撮合 + 只转发」是 T2 的目标架构。
- 5 版协议增加全房间共享审计压力，所有成员共同承担危机，也可以共同缓解。

### 4. 反作弊：不落盘 + 帧同步互验（目标架构）

- 联机对局数据**只存在参与者客户端内存里**，不写本地文件、不上传服务器、关房即焚。
- 服务器不保存任何对局状态，进程重启 = 所有房间消失。
- 所有客户端跑同一套确定性规则，每隔一段时间交换状态哈希。
- 谁的数据和别人不一致，谁就被判定「时空失真」：回滚、重同步、标记，严重者移出本局。
- 执事只是会话协调人，消息由服务器转发，不能单方面改资源、改战斗结果。

> 诚实说明：纯客户端内存 + 帧同步能防住存档篡改、事后改分、单方面改数据，但防不住所有合谋作弊。竞技/排名模式需要额外的「公证模式」，详见联机文档。

### 5. 单机与联机分开

- **单机模式**：保留本地存档，适合挂机和一个人慢慢玩。
- **联机模式**：不落盘，一局一清，公平优先。
- 两套模式共用同一套玩法规则，但数据通道完全隔离。

### 6. 玩家之间可以贸易，也可以掠夺

贸易和掠夺不是两个孤立按钮，而是同一张星区经济的两面：

- **贸易**：资源互换、长期贸易路线、护航合同、关税、走私、黑市。
- **掠夺**：劫商路、抢仓库、抓人口、拆船坞、绑票、悬赏。
- 贸易路线越肥，越值得抢；护航越强，掠夺风险越高。
- 所有贸易最终都绕不开**星际代币（ST）**：卖资源、签合同、抢商队、探险打捞，最后都要去黑市花掉。
- 你可以当商人、当护航者、当私掠者，也可以白天做生意晚上抢客户。
- 所有行为都会留下「信誉」：护航、履约、救灾加分；背刺、劫掠、撕约减分。

> 当前原型已实现市场买卖、合同、黑市、信誉和玩家劫掠/占领；贸易路线、护航、保险、关税、走私仍是目标设计。

这样，四到八个玩家之间就不只是「谁舰队大」，而是「谁值得合作、谁该被围剿」。

### 7. 军队可以编组去探险

舰队不只是用来打仗，也可以编成远征队去未知区域：

- 在舰队页选择舰船、指挥官、补给和风险姿态，组成 1–3 支远征队。
- 目的地包括遗迹带、深空异常、漂流方舟、静默区边缘和未探索扇区。
- 探险可以获得稀有资源：遗物、星核、数据核心，以及科技、地图情报、殖民点和独特模块。
- 探险有真实损失：舰队可能被击毁，指挥官可能被俘，科研船可能丢失数据。
- 越深入，收益越大，损失也越大；可以随时召回，但拿不到完整战利品。
- 探险也是剧情来源：回声、旧帝国遗迹、静默者的秘密，都从远征报告里出来。

探险让「军队」不只是战争的工具，也是探索、考古、赌运气和讲故事的载体。

> 当前原型：远征页直接选择目的地与谨慎/深入姿态，舰队仍是单一数字；舰船编组、指挥官和模块是目标设计。

### 8. 星际代币与黑市

**星际代币（Stellar Token，ST）**是裂谷时代的硬通货，也是本作唯一的「钱」。

- 它不是生产资源，不能靠建矿场刷出来。
- 来源：市场卖资源、贸易合同、贸易路线、掠夺商队、探险打捞、悬赏。
- 用途：黑市买稀有科技/模块/遗物/星核/情报、雇佣兵、赎金、保险、政治献金。
- 黑市库存全房间共享，每 15 分钟刷新，稀有货先到先得。
- 价格会随战争、封锁、危机和信誉波动；赫卡忒对你的态度会影响报价。
- 星际代币只在当前对局有效，关房即焚；不能充值，不能提现，不能跨局继承。
- 它不计入霸业值：**花出去才算数，囤着只是数字。**

这让星区多了一条完整的「赚钱 → 花钱 → 变强 → 继续赚钱」循环，
也让「有钱但没兵」和「有兵但没钱」都成为真实处境。

## 设计支柱

### 支柱一：伪装

外观永远是系统性能监视器。任务栏控件显示 CPU / 内存 / 网络 / 磁盘，点开是进程列表。
按 `Alt+Q` 才切成领主面板。

**伪装不是皮肤，是世界观的一部分。** 旧帝国的领主权柄被伪装成民用监控软件，用来躲过「审计者」的扫描。

### 支柱二：30 秒

任何一次操作，30 秒内必须能完成。

- 弹窗最多 6 行可见。
- 不搞实时微操，不搞编队框选。
- 所有生产、研究、舰队都可以排队。
- 离开半小时，帝国不会崩；回来一定有事做，但不是一地红点。

### 支柱三：真决策

每个循环节点至少有一个**互斥选择**，而不是「有钱就点」。

- 科技二选一。
- 殖民地专业化互斥。
- 舰队配比克制。
- 占领还是劫掠。
- 帮邻居还是趁火打劫。

### 支柱四：一起玩

- 房间制，不搞开放世界 MMO。
- 人人可当执事，执事可迁移。
- 统一平民开局，没有氪金起跑线。
- 合作与背刺都允许，但背刺有代价。

### 支柱五：不落盘

联机对局只在内存里活着。

- 没有云存档。
- 没有排行数据库。
- 没有「上局遗产」。
- 每局都是新的文明。

## 三条核心承诺

1. **你离开半小时，帝国不会崩。**
   目标设计：离线托管会按你设定的方针继续发展，效率降低，但不会自杀式操作。
   单机随时回来继续；联机座位保留 15 分钟（前 5 分钟可快速重连），超时后帝国仍会托管到本局结算。

2. **你回来，一定有事可做，但不是一地红点。**
   事件以「待办」形式排队，最多 8 条；超出自动按保守选项结算。

3. **你的对手是人，不是数值。**
   中立势力只是节奏工具，真正的变数来自其他领主的选择。

## 目标玩家

- 上班摸鱼、开会摸鱼、等编译的人。
- 喜欢《文明》《群星》但没时间开一局长局的人。
- 喜欢和朋友开黑，但不想打高强度竞技的人。
- 喜欢「看起来在工作，其实在打游戏」的人。

---

## 不做什么

- 不做全屏 3D 星图。
- 不做实时单位框选和微操。
- 不做账号系统、云存档、好友系统。
- 不做抽卡、体力、红点、弹窗广告。
- 不做真实货币、付费代币、现金交易。
- 不做需要语音沟通的高强度竞技。
- 不做持久化排行榜（至少 MVP 不做）。

## 与现有原型的关系

现有代码已经具备：

- 任务栏嵌入与伪装。
- `Alt+Q` 模式切换。
- 能源 / 矿物 / 食物 / 合金 / 科研 / 人口；影响力、星际代币、稀有资源、信誉。
- 6 种建筑、6 条科技、殖民地、舰队、进攻。
- 4 条治国路线、士气、3 座奇观、11 张事件卡、指令卡。
- 市场、合同、黑市、远征、玩家劫掠与占领。
- 全房间共享审计压力，40 / 65 / 85 三档共享危机与缓解动作。
- 4 位房间码、创建/加入/开始、执事标记；准备接口已预留。
- 客户端轮询房间状态、服务端下发状态串；当前协议 v5。

这套文档保留这些骨架，重点补三件事：

1. **让循环更好玩**：补上职业分配、科技二选一、舰船模块、星区地图、占领控制度；把已有的奇观、事件卡、贸易/掠夺/探险、星际代币与黑市做深。
2. **让联机更公平**：统一平民开局、确定性帧同步、状态哈希互验、执事迁移。
3. **让世界观和 UI 长在一起**：任务栏伪装、加入时空、执事、平民、回声，全部有叙事解释。

具体实现节奏见 [03-玩法设计.md](03-玩法设计.md) 的「MVP 与路线图」。
